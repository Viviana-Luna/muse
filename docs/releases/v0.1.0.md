# Muse v0.1.0

Muse 的第一个公开版本完成了桌面角色助手、会话运行时、本地模型资产和多供应商模型接入的基础闭环，并将本地数据统一保存到当前用户主目录下的 `~/.muse`。

## 主要能力

- 内嵌 Tauri 桌面界面，不依赖源码目录、固定端口或外部前端服务器。
- 支持角色、会话、流式聊天、工具调用、审批、用户问答和回合取消。
- 支持 OpenAI、Anthropic 与 DeepSeek 模型能力，以及可配置的 Web Search 和语音能力。
- 模型资产支持受控上传、外部只读引用、校验和验证与异步下载任务。
- Session v3 提供原子 generation、事件序号、隔离记录和崩溃恢复边界。

## 安全与数据

- 桌面本地 API 默认使用随机回环端口和仅存于内存的 Bearer，并校验 Host、Origin 与请求权限。
- 桌面和 headless 共用 `~/.muse`，并通过数据目录独占锁阻止并发写入。
- 外部模型文件只会被验证和引用；清除引用不会删除原始文件。
- 密钥不会写入配置响应、运行日志或发布产物。

## 安装说明

- macOS 13.1 或更高版本：下载 DMG，挂载后将 Muse 安装到 Applications。
- Windows 10 22H2 或 Windows 11：下载 NSIS 安装程序并按提示完成安装；缺失或低于 WebView2 111 时，安装器需要联网安装或更新运行时。
- 可使用同一 Release 中的 `SHA256SUMS` 校验安装包完整性。

本版本的 CI 安装包尚未进行商业代码签名或 macOS 公证，操作系统可能显示来源或开发者警告。请只从本仓库的正式 GitHub Release 下载，并在安装前核对 SHA-256。

数据迁移和本地 API 说明分别见[升级与数据迁移](https://github.com/Viviana-Luna/muse/blob/master/docs/upgrade.md)和[本地 API 协议](https://github.com/Viviana-Luna/muse/blob/master/docs/local-api.md)。
