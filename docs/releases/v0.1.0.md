# Muse v0.1.0（未发布历史草案）

> 本文件是早期发布流程留下的历史草案，不代表 Muse 已经发布 v0.1.0，也不是安装或支持说明。Muse 当前仍处于功能与架构开发阶段，尚未进入 Alpha、Beta、RC、发布候选或正式发布准备阶段；当前没有正式版本标签、公开安装包或 GitHub Release。

草案中原有的能力、供应商、模型资产和双平台完成声明已经与当前产品事实不一致，不再保留。真实能力以 README、当前代码和公开协议文档为准。

## 当前平台口径

- macOS 是当前主要开发、长期自用和真实桌面验证环境。代码保留 macOS 13.1 / Safari 16.2 技术基线，但最低系统、Developer ID 签名、公证和公开分发尚未进入评估。
- Windows 10 22H2、Windows 11 与 WebView2 111 是未来适配目标；当前不宣称 Windows 已受支持，不提供正式 NSIS 安装包。
- 任何未来版本都必须重新建立独立发布计划、冻结目标平台与安装包，并重新生成 `SHA256SUMS`，不得复用本草案。

数据迁移和本地 API 说明分别见[升级与数据迁移](https://github.com/Viviana-Luna/muse/blob/master/docs/upgrade.md)和[本地 API 协议](https://github.com/Viviana-Luna/muse/blob/master/docs/local-api.md)。
