# Muse v1.0.0-beta.2

`v1.0.0-beta.2` 是 Muse 的 Windows 11 25H2 x64 源码支持基线。该标签只在同一提交与同一 NSIS 内部测试包完成自动化、安装升级、ACL、配置、产品主链、DPI、数据重建和进程生命周期验收后创建。

## 平台范围

- 支持 Windows 11 25H2 x64（build 26200）与 Evergreen WebView2 111+；固定实机为 Windows 11 Pro 25H2 x64。
- Windows 10、Windows 11 24H2/26H1、ARM64、Windows Server 和 Linux 不在支持范围。
- macOS 继续作为主要开发与长期自用环境，但该标签不建立 macOS 公开分发承诺。

## 分发边界

- 本标签只冻结源码并运行 quality，不提供公开或签名 NSIS，不创建 GitHub Release。
- Actions 生成的安装包只用于与该提交绑定的内部验收，不构成公开下载资产或稳定版发布。
- 稳定标签、`master` 提升、签名、公证、自动更新和正式 Release 仍需独立版本阶段决策。

## 主要变化

- Windows 自绘标题栏改为右上角最小化、最大化或还原、关闭控件，并保留 macOS 原生红绿灯。
- Windows 标题栏改为左侧会话上下文与右侧窗口控件双浮岛布局，外观设置新增默认实色、可选半透明的应用画布。
- Windows 实机证据协议升级为 `muse-windows-acceptance-evidence/v2`，只接受 25H2 build 26200、x64 和 WebView2 111+。
- 当前 `config.toml` 单一事实源、ACL、Provider/MCP/Exa 秘密边界、Session JSONL 与可重建 SQLite 索引继续作为支持验收契约。
